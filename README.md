# 非绝热载流子动力学理论计算方法

> 一份从 Tully 最小面跳跃（FSSH）推导到 PYXAID 实操参数的中文教程，覆盖 KS 轨道近似、经典路径近似（CPA）、DISH 退相干修正与 VASP 相位修正。

本仓库是一份**学习型笔记 / 教程**，目标是把"面跳跃 + 非绝热分子动力学"这条链路从第一性原理一路推到能真正跑起来的 PYXAID 计算：公式尽量给全、每一步推导的动机都写清楚、数值实现中容易踩的坑（尤其是相位随机性问题）单独成章。
